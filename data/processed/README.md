# Processed UEBA Feature Profiles

This directory will store processed artifacts generated by the ingestion and feature engineering pipeline:
- `user_day_profiles.parquet` / `.csv`: Daily aggregated behavioral metrics per user.
- `personal_baselines.json`: Computed historical mean, variance, and robust thresholds for each user.
- `train_val_test_splits/`: Chronological train/validation/test partitions avoiding data leakage.
